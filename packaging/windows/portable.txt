TSPhoto portable mode

While this file sits next to tsphoto.exe, TSPhoto keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the TSPhotoData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move TSPhoto with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\TSPhoto for settings
and %LOCALAPPDATA%\TSPhoto\Recovery for crash-recovery autosaves. If TSPhotoData can't be
written (for example on a read-only drive), TSPhoto says so and uses those folders instead.
